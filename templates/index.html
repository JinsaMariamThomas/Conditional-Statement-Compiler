What is a compiler?

A compiler is a program that analyzes source code and checks whether it follows the rules of a programming language. It helps identify problems in the code.

IF

What is a conditional statement?

A conditional statement lets a program choose what to do based on a condition. For example, if a number is greater than 10, do one thing; otherwise, do something else.

i

Does this website run my program?

No. This educational project analyzes your code and reports its results. It checks the code but does not execute the entered program.
